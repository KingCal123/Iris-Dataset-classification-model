Model & Setup Details
🌲

Random Forest Classifier

100 decision trees with random_state=42. An ensemble method that reduces variance through bagging and random feature selection.

🌸

Iris Dataset

150 samples · 4 features (sepal length, sepal width, petal length, petal width) · 3 balanced classes: Setosa, Versicolor, Virginica.

✂️

Train / Test Split

80% training (120 samples) · 20% testing (30 samples). Stratified sampling to preserve equal class proportions in both splits.

🧪

Stack

Python 3.13 · scikit-learn 1.9 · pandas 3.1 · numpy 2.5 · matplotlib 3.11 · seaborn 0.13 · Flask 3.1
